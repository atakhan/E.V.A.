# Гипотетическая модель работы аналитического бюро

> Целевая конституция этажа E.V.A. Не описание текущего кода и не план внедрения. Не новые сущности в продукт — см. [`INTERACTION_FUNDAMENTAL_PROBLEM.md`](./INTERACTION_FUNDAMENTAL_PROBLEM.md).  
> Стык со стойкой — [`INTERACTION_OFFICE_MODEL.md`](./INTERACTION_OFFICE_MODEL.md). Три проекции ситуации — [`INTERACTION_WORLD_MODEL.md`](./INTERACTION_WORLD_MODEL.md). Сверка с живой сборкой — [`INTERACTION_OFFICE_GAP.md`](./INTERACTION_OFFICE_GAP.md).  
> Язык — контора. Машинные имена — только в приложении.

Документ отвечает: *как бюро должно работать, чтобы остаться тем же бюро, когда появится десятый специалист и третий штамп.* Устойчивость здесь — инварианты и виды документов, а не список ключевых слов.

Можно опереться на уже найденное: факт не команда; должность = процесс класса задач; у двери слой до специалиста; оригиналы не переезжают в бюро; закон — переизданный регламент. Нельзя опереться на костыль «подменить бланк, чтобы старый стол понял».

---

## 1. Чем бюро является

Бюро — этаж, который **принимает неизменный конверт**, **ведёт папки дел**, **думает по регламенту** и **отдаёт пакет стойке**. Оно не лицо конторы и не архив заявок.

Три продукта бюро, не больше:

1. **Решение регистратора** — куда положить этот конверт (или закрыть какую папку, или переспросить).
2. **Движение папки** — открыть / продолжить / поправить / закрыть.
3. **Пакет вниз** — что сказать, что вписать, какие ярлыки, какая табличка.

Всё остальное (как специалист разбирает заявку, какой консультант за ширмой) — внутри папки. Конституция бюро до папки не заходит дальше, чем виды ожидания: иначе снова смешаются этажи.

---

## 2. Инварианты

Эти правила не меняются, когда методист добавляет должность или штамп. Если новое решение их ломает — это не развитие бюро, а другая организация.

**Б1. Конверт не переписывают.**  
В журнале остаётся то, что пришло: речь это или штамп, какие бумаги, чья рука. Регистратор выпускает **отдельный листок решения**. Специалист читает исходный конверт плюс решение. Подмена «сказал, а записали как штамп» запрещена.

**Б2. Регистратор не судит поставку.**  
Он классифицирует *акт относительно открытых папок, приложенных бумаг и справочника должностей*. Он не понимает «мешки», «Север» и единицы измерения. Если для выбора папки нужно понять содержание — это уже работа специалиста или переспрос.

**Б3. Собеседник не начальник.**  
Нить разговора не даёт права открывать чужие дела. Рабочее слово в трубке не делает собеседника делопроизводителем.

**Б4. Папка ≠ трубка.**  
На одной трубке — ноль или несколько папок. Собеседник на трубку один. Делопроизводители — по делам.

**Б5. Специалист объявляет, чего ждёт.**  
В каждом положении папки видно: ждём штамп такого-то вида, ждём речь в трубку, ждём факт «бумага изменилась», ждём ответ консультанта, или не ждём ничего внешнего. Регистратор кладёт конверт в папку, только если вид ожидания совпал. Иначе это не «ответ этой работе».

**Б6. Копия стола старше факта правки — ложь.**  
Перед речью о числе и перед листком в архив бюро снимает свежую копию. Черновик на столе специалиста не цитируют, если после него приходил факт правки.

**Б7. Пакет собирает экспедиция, не специалист в одиночку.**  
После шага папки бюро обязано отдать стойке пачку: речь (можно пустую), правки, ярлыки, табличку. Табличка считается всегда, даже если речи нет.

**Б8. Закон — печать, не черновик методиста.**  
Дежурная смена работает по переизданному регламенту: список должностей, справочник штампов и фраз регистратора, положения и ожидания специалистов.

**Б9. Новая должность не меняет регистратуру.**  
Появляется строка в справочнике: какие штампы и какие классы фраз открывают эту должность, одно ли дело на бумагу. Алгоритм регистратора (§6) тот же.

## 3. Документы бюро

Устойчивость модели — в том, что виды бумаг фиксированы. Меняется содержимое, не канцелярия.

| Документ | Что в нём | Чего в нём нет |
|----------|-----------|----------------|
| **Конверт** | Факт акта. Речь или штамп, бумаги перед глазами, рука, время. Можно приложить копию стола | Команды «открой разбор». Имени специалиста, обязанного это выполнить |
| **Листок решения** | Класс акта, какая папка, какую должность открыть, какие папки закрыть, нужен ли следом собеседник | Переписанный факт. Толкование поставки |
| **Папка дела** | Должность, трубка, бумаги дела, положение по регламенту, черновик, журнал шагов | Оригиналы заявок. Вся история чата как истина |
| **Справочник должностей** | Из печати: кто есть, какие штампы принимает, какие классы фраз открывают должность, синглтон ли собеседник, ключ дела (на трубку / на бумагу) | Понимание текста заявки |
| **Копия стола** | Снимок архива на момент T | Право считаться оригиналом после T |
| **Пакет вниз** | Речь, листки в архив, ярлыки и готовый штамп, табличка | Выбор «только чат» |

Конверт хранят. Листок решения прикладывают к нему. Если завтра будут спорить, почему открыли разбор, спорят с листком, не с поддельным штампом.

## 4. Штат и полномочия

| Роль | Полномочие | Предел |
|------|------------|--------|
| **Экспедитор** | Несёт конверты, не даёт двум людям одновременно сидеть за одной папкой | Не классифицирует |
| **Регистратор** | Пишет листок решения по §6 | Не меняет конверт. Не вызывает консультанта |
| **Собеседник** | Одна папка на трубку. Отвечает, переспрашивает, говорит о процессе | Не открывает должность разбора |
| **Делопроизводитель** | Ведёт папку своей должности по регламенту | Не слушает конверт, которого его положение не ждёт |
| **Консультант** | По шагу «сделай» смотрит копию и предлагает текст или разбор полей | Не выбирает папку. Не говорит со стойкой |
| **Методист** | Печатает регламент и справочник | Не дежурит |

За столом одной папки в один момент — один исполнитель. Это не «вся трубка занята». Собеседник может говорить, пока делопроизводитель ждёт консультанта — если экспедитор не держит их одним замком на весь кабинет.

## 5. Виды ожидания

Это единственный язык, которым папка разговаривает с регистратором. Не «я жду любое событие этой трубки».

| Вид | Пример | Кто кладёт конверт в эту папку |
|-----|--------|-------------------------------|
| **Штамп S** | «Разобрать», «Подтвердить» | Штамп S или фраза *того же класса*, что справочник приравнивает к S — **без подмены бланка**: в папку идёт исходная речь, решение говорит «это класс S» |
| **Речь** | Спросили единицу, ждут ответ | Следующая речь, если это не стоп, не новое поручение и не вопрос мимо |
| **Правка бумаги** | Директор сам сменил число | Факт «бумага изменилась» по этой карточке |
| **Ответ консультанта** | Шаг «сделай» закончен | Внутренний конверт. Регистратор человека здесь не классифицирует |
| **Тишина** | Готовы взять новое дело этой должности | Только **открытие** новой папки, не «любая речь трубки» |

П9 конторы («мешки» закрывают уточнение) выполняется так: положение «спросили единицу» объявляет ожидание **речи**. Регистратор кладёт «мешки» в эту папку. Справочник регистратора не содержит слова «мешки».

Если должность в положении «готова» объявляет только штампы и не объявляет речь — свободный ответ в трубку ей не принадлежит. Это не дырка регистратора. Это дырка регламента должности. Конституция запрещает чинить её словарём у двери.

## 6. Регистратура: устойчивый алгоритм

Вход: конверт, открытые папки этой трубки, справочник печати, при необходимости копия стола.  
Выход: один листок решения. Конверт не изменён.

Порядок жёсткий. Первое совпадение побеждает. Так модель остаётся предсказуемой, когда справочник растёт.

**0. Внутренний конверт** (ответ консультанта, продолжение шага).  
Положить в указанную папку. Стоп.

**1. Факт правки бумаги.**  
Есть папки с ожиданием «правка» по этой бумаге → положить туда. Иначе — только расписка: папку не открывать, речь не обязательна. Стоп.

**2. Стоп / отказ.**  
Класс фразы или штамп «стоп» по справочнику. Закрыть указанные папки (по бумагам конверта; если бумаг нет — рабочие папки, не собеседника, либо спросить «все?»). Трубку не ломать. Обычно следом — собеседник коротко подтверждает. Стоп.

**3. Недоопределено.**  
Есть указание «это/эти», бумаг в конверте нет → собеседник переспрашивает. Не открывать разбор. Стоп.

**4. Новое поручение или штамп известной должности.**  
Справочник: этот штамп или этот *класс фразы* открывает должность R.

- Есть открытая папка R, которая **ждёт** этот класс (штамп S или эквивалент) и совпадает по бумагам → положить в неё.
- Есть открытая папка R по тем же бумагам, но она не ждёт этот класс → это не ответ; либо поправка (§ шаг 5), либо спросить, либо закрыть-и-открыть как **перенаправление** (честное имя, не «поправка»).
- Папки нет, бумаги есть → открыть папку R на этих бумагах.
- Папки нет, бумаг нет, в тексте нет «это» → **не** открывать молча пол-архива. Либо переспрос, либо открыть неполную папку, если регламент R это явно разрешает (план на стол). Молчаливый захват архива запрещён.

**5. Поправка.**  
Класс «сначала / только эти» и есть живая рабочая папка.

- Бумаг нет → переспрос.
- Бумаги есть и папка **объявляет**, что принимает поправку в этом положении → положить в **ту же** папку (вид ожидания «штамп/речь класса поправка» или отдельный вид «поправка»).
- Папка поправки не принимает → честное **перенаправление**: закрыть и открыть новую. В листке написано «перенаправление», не «поправка».

**6. Согласие («да», штамп подтвердить).**  
Положить в папку, только если она **ждёт** согласие / штамп ревью. Живая рабочая папка сама по себе не делает «да» одобрением. Иначе — к собеседнику.

**7. Речь в папку, которая ждёт речь.**  
Есть папка с ожиданием «речь», конверт — речь, и это не стоп, не новое поручение, не вопрос мимо (класс «кто/что/?»). Положить в эту папку. Если таких папок несколько — различить по бумагам; не различили — переспрос.

**8. Иначе — собеседник.**  
Вопрос мимоходом, болтовня, «как идёт». Рабочие папки не трогать.

Справочник классов фраз (разбор / стоп / поправка / вопрос мимо / согласие) — **настройка печати**, не конституция. Конституция — шаги 0–8 и запрет трогать конверт. Сменить язык = переиздать справочник, не написать нового регистратора.

## 7. Папка дела

### Ключ

- Собеседник: одна папка на трубку. Пока она в «делает» (ждёт консультанта), вторую не открывают: речь встаёт в очередь к той же папке или ждёт у экспедитора. Это синглтон должности, не синглтон кабинета.
- Делопроизводитель R: ключ **трубка + должность + бумаги дела**. Две карточки — две папки. Одна карточка — одна папка R. Вторая просьба по той же карточке — в ту же папку, если она жива.

Так снимается ложная дилемма «один замок на должность на всю трубку» против «форк собеседника». Замок экспедитора — на **папку**, плюс короткий замок «ещё нет собеседника на этой трубке».

### Жизнь

```text
открыть → делать (шаг регламента) → ждать (один из видов §5)
        → делать → …
        → закрыть (готово | стоп | перенаправление)
```

Журнал папки хранит конверты **как пришли** и листки решений. Поправка не стирает журнал.

### Внутри папки (граница конституции)

Регламент должности: ждать / сделать / решить. «Сделать» может позвать консультанта. Консультант возвращает внутренний конверт. Регистратор человека здесь молчит (шаг 0).

Конституция требует от регламента только одно: в каждом положении явный вид ожидания. Без этого регистратор снова начнёт врать в бланке или собеседник снова станет начальником.

## 8. Копия стола

- Снимать копию: перед шагом, который называет число, и перед листком правки в архив. Не обязательно перед каждым «кто по арматуре», но тогда собеседник не имеет права назвать количество.
- Копия живёт на папке с меткой времени. Факт правки бумаги делает старую копию недействительной для цитат.
- Если снять копию не удалось, шаг, который обязан цитировать стол, **ждёт**, а не падает как «должность сломалась» и не выдумывает число.

Бюро по-прежнему не хранит оригиналы. Копия — очки, не второй архив.

---

## 9. Пакет вниз

После шага, который что-то меняет для директора, экспедиция собирает пачку. Пустые слоты допустимы. Отсутствующая табличка — нет.

| Слот | Когда обязателен |
|------|------------------|
| Речь | Директор ждал ответ в трубку; переспрос; подтверждение стопа |
| Листок в архив | Поручение меняло дело |
| Ярлыки / готовый штамп | Бюро спрашивает согласие или указывает набор карточек |
| Табличка | Всегда: список живых папок, чем заняты, ждут ли директора |

Табличка не едет «прицепом к фразе». Допустим пакет из одной таблички (стоп без разговора, факт правки, если политика молчать).

Стойка исполняет пачку целиком. Неисполненный ярлык — поломка стойки, не бюро. Конституция бюро всё равно обязана ярлык класть, когда спрашивает согласие с набором (иначе П9 не из чего собрать на столе).

---

## 10. Печать

Переиздание — единственный способ сменить:

- список должностей;
- справочник штампов и классов фраз;
- регламенты положений и ожиданий;
- тексты, которые велят смотреть стол.

Пока печать старая, дежурная смена не «почти» работает по черновику. Разрыв черновика и печати — операционный факт, его нельзя замазать правкой репозитория.

Методист не дежурит. Конструктор должностей — его кабинет. Смешивать кабинет методиста со стойкой директора нельзя.

---

## 11. Что берём из нынешней архитектуры

Не с нуля в пустоте. Ниже — наработки, которые **совпадают** с этой конституцией.

| Наработка | Зачем в бюро |
|-----------|----------------|
| Факт ≠ команда | Б1: конверт не переписывают |
| Должность = процесс класса задач (ждать / сделать / решить) | Внутри папки; не один универсальный собеседник |
| Поступок = рецепт, инструмент без права вести дело | Консультант и руки, не начальник |
| Слой у двери до выбора должности | Регистратор |
| Продолжить папку, только если положение ждёт этот *вид* | Б5; сейчас вид подменён «типом бланка» — конституция отделяет вид в листке решения от бланка конверта |
| Одна трубка, много папок | Б4 |
| Оригиналы у стойки, снимок по запросу | Б6 |
| Пачка: речь + правка + ярлык + табличка как *замысел* исходящего | Б7 |
| Неизменная публикация | Б8 |

Что **не** переносим как принцип, даже если сейчас помогает:

- подмена бланка речи штампом;
- замок «одна должность на всю трубку» как замена замка на папку;
- табличка только вместе с фразой;
- «да» = одобрение любой живой рабочей папки;
- молчаливое открытие разбора без бумаг;
- поправка = закрыть и открыть, названная поправкой;
- имя специалиста, написанное стойкой на штампе, как обязательный вход.

Листок решения уже почти существует в наработках (класс акта, какая папка, кого закрыть). Конституция делает его **единственным** способом командовать, а конверт оставляет фактом.

## 12. Как выглядит один ход (без подмены)

Директор: открыта карточка, говорит «разбери это».

1. Стойка кладёт в конверт речь, номер карточки, доску, руку. Имя специалиста не пишет.
2. Регистратор: шаг 4, класс «разбор», бумаги есть, папки разбора нет → решение «открыть должность разбора на этой бумаге». Конверт по-прежнему речь.
3. Экспедитор открывает папку. Специалист видит: пришла речь класса «разбор» про эту бумагу. Снимает копию. По регламенту делает шаг. Может позвать консультанта.
4. Пакет вниз: вписать статус, сказать коротко, обновить табличку. Если не хватает единицы — речь с вопросом, ярлык на карточке, положение папки: ждать **речь** (и штамп, если положили «подтвердить»).
5. Директор: «мешки». Регистратор: шаг 7, папка ждёт речь → положить туда. Собеседник не участвует.
6. Директор среди этого: «кто по арматуре?». Шаг 8 → собеседник. Папка разбора жива.

Тот же разбор штампом «Разобрать»: шаг 4, штамп известен справочнику, бумаги на штампе. Решение «открыть / продолжить разбор». Конверт — штамп. Одна должность, два бланка, без лжи о том, что случилось.

---

## 13. Что модель сознательно не закрывает

Чтобы не раздувать конституцию.

- Два директора у одного стола: на конверте уже есть рука; правило конфликта — отдельная печать, не регистратура.
- Свой телефон бюро на улицу: допустим, если директор по-прежнему слышит только стойку. Политика «входящее сначала бумага» живёт на стойке; бюро принимает *факт появления бумаги*, не второго абонента.
- Глобальная очередь «что делать завтра утром» (планировщик): это не регистратор очередного конверта.
- Как именно консультант понимает текст заявки: внутри шага «сделай».
- Зрение стойки (ряд карточек): это стойка, не бюро. Бюро имеет право переспросить, если ряд пуст.

---

## 14. Критерий устойчивости

Модель устойчива, если можно сделать три вещи, **не меняя §2 и §6**:

1. Добавить должность «согласовать счёт» со своим штампом и классом фразы — строка в справочнике печати.
2. Добавить положение «ждём единицу» с ожиданием речи — «мешки» начнут попадать в папку без нового словаря у двери.
3. Сменить язык справочника фраз — переиздать печать, алгоритм 0–8 тот же.

Если для новой должности снова хочется переписать конверт или научить собеседника открывать дела — конституция нарушена.

## Приложение. Перевод на машины

Читать, когда нужно сопоставить бюро с E.V.A.

| В бюро | В системах |
|--------|------------|
| Конверт | Event как факт; `type` не меняют |
| Листок решения | `DispatchDecision` (класс, skill, run, cancel); единственный вход роутера |
| Справочник должностей | Публикация агента: skills, initial events, таблица классов фраз |
| Папка | Skill Run |
| Ключ папки собеседника | одна run разговорного скилла на `conversation_id` |
| Ключ папки делопроизводителя | `conversation_id` + `skill_id` + `entity_id`(s) |
| Вид ожидания | current_state: какие event types / классы актов ждут; речь как класс, не как поддельный `ui.*` |
| Положение ждать / сделать / решить | Behavior Graph → FSM |
| Консультант | LLM (или другой tool) в Action recipe |
| Копия стола | snapshot в vars с меткой; invalidate по `web.state.changed` |
| Пакет вниз | текст + workspace_update + ui.proposal + presence; presence можно без текста |
| Печать | immutable publication |
| Экспедитор / замок на папку | worker lock на run (и create-guard собеседника) |
| Запрещённая подмена бланка | `_rewrite` Event.type |

Канон исполнения одной уже выбранной папки по-прежнему SKILLS / BEHAVIOR / RUNTIME. Этот файл — конституция этажа **до** и **вокруг** папки: регистратура, виды ожидания, пакет, печать.
