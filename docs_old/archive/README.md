# Архив документации

Сюда складываются спеки и заметки, которые **больше не канон**. Их не использовать при реализации холста, runtime или publish.

Актуально:

- конструктор Skills — [`../SKILLS_CONSTRUCTOR.md`](../SKILLS_CONSTRUCTOR.md) (FSM, `states[]`);
- визуальный язык холста — [`../FSM_CANVAS_STYLE.md`](../FSM_CANVAS_STYLE.md);
- геометрия стрелок — [`../FSM_CANVAS_GEOMETRY.md`](../FSM_CANVAS_GEOMETRY.md);
- исполнение — [`../SKILLS_SPEC_v0.1.md`](../SKILLS_SPEC_v0.1.md), [`../RUNTIME_SPEC_v0.1.md`](../RUNTIME_SPEC_v0.1.md).

| Файл | Почему в архиве |
|------|-----------------|
| [`BEHAVIOR_SPEC.md`](./BEHAVIOR_SPEC.md) | Конструктор Behavior Graph (`wait` / `do` / `decide`), вкладки История · Логика, compile в FSM на publish |
| [`NEW_CONSTRUCTOR_DESC.md`](./NEW_CONSTRUCTOR_DESC.md) | Видение «Story + semantic model + FSM». Нарратив как отдельный слой |

Слой взаимодействия (`INTERACTION_*`) здесь не лежит: это другая тема. В тех текстах ещё могут мелькать старые имена конструктора — канон редактора всё равно FSM.
