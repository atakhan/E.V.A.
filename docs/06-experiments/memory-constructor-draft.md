# Черновик режима конструктора «Память»

> 2026-11-06. Каркас UI и роли полок. Actions записи в память и установка кусков из навыков — следующий слой.

## Инвариант

Память — **орган агента** и **масштаб стола**: карточка летит в центр, грани на packed-орбите, не боковая панель. Зона внимания — ёмкость сцены, не тип знания.

## Семь задач → сателлиты

| Id | Подпись | Роль | В черновике |
|----|---------|------|-------------|
| `self` | О себе | знание о себе | пустая полка |
| `life` | Жизнь | main log | runtime-события как временный ствол |
| `outcomes` | Вехи | достижения/провалы | пусто: пишет только навык через memory Actions |
| `tasks` | Задачи | актуальное | активные прогоны |
| `others` | Другие | агенты/люди | `memory.interaction` |
| `skills` | Навыки | куски навыков | список навыков + «память не установлена» |
| `focus` | Внимание | зона внимания | до `MEMORY_ATTENTION_CAPACITY` карточек |

## Орбита

Полный круг вокруг центра памяти. Радиус center→center = **три иконки** (`MEMORY_ORBIT_RADIUS = 3 × MEMORY_SAT_SIZE`). Сиденье = `AGENT_ICON`. Равномерно по окружности, первый слот сверху.

## Режим полки (слой)

Клик по сателлиту — one-pass как канал→слой: выбранный раздел летит в центр; остальные схлопываются в «Память»; справа колонка **карточек** содержимого (`MemoryFacetCards`). Escape / «К памяти» — обратно на круг.
