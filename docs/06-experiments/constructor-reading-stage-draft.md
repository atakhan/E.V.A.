# Reading stage — правая половина конструктора

> 2026-11-06. Черновик поверхности для контента детали (сейчас: фасет плагина).  
> Код-токены: [`frontend/src/features/constructor/utils/readingStage.ts`](../../frontend/src/features/constructor/utils/readingStage.ts).

## Назначение

Когда на столе открыт zoom на деталь (иконка в центре), **смысл детали** читается справа — не в карточке/панели, а в **размытой половине экрана** (blur сильнее у правого края, на левой границе области — ноль).

## Геометрия (сейчас)

| Правило | Значение |
|---------|----------|
| Граница области | Правая **половина** viewport (`50vw`) |
| Поля | Канон страницы Ван де Граафа / Чихольда (девятины): на этой половине как на *recto*-странице |
| Внутреннее (к центру стола) | **1/9** ширины половины ≈ `50vw / 9` |
| Внешнее (правый край экрана) | **2/9** ширины половины ≈ `100vw / 9` |
| Верх | **1/9** высоты viewport |
| Низ | **2/9** высоты viewport |
| Шрифт | Адаптивный `clamp` от ширины viewport (не фиксированные `text-xs`) |

Источник пропорций полей: [Canons of page construction](https://en.wikipedia.org/wiki/Canons_of_page_construction) (Van de Graaf / Tschichold, деление страницы на 9).

## На будущее (зафиксировать)

Эта область — **отдельный дизайн-контракт**, не «ещё один daisyUI panel».

Желаемый режим (ещё не реализован):

1. **Allowlist элементов** — разрешены только согласованные классы контента:
   - типографика (заголовки, абзацы, mono-метки);
   - формы (поля, селекты, простые controls);
   - анимация появления/смены смысла (one-pass с полётом фасета).
2. Всё остальное (карточки, тяжёлые sheets, чужой chrome) — **вне** reading stage.
3. Позже: общий компонент/скин для памяти, канала и др., когда они переедут на ту же правую половину.

Пока: плагин-фасет уже сидит в этой геометрии; allowlist — требование на следующий проход, не смешивать с орбитальной физикой.
