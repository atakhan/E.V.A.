# Принципы пространственного UI конструктора

> Сформированы на практике при сборке лестницы режимов: стол Евы → конструктор Евы → стол проекта → конструктор агента → канал/слой (2026-11-06).  
> Ретроспектива: [`../06-experiments/constructor-spatial-modes-retrospective.md`](../06-experiments/constructor-spatial-modes-retrospective.md).  
> Правило агента (alwaysApply): [`.cursor/rules/spatial-ui-design.mdc`](../../.cursor/rules/spatial-ui-design.mdc).

Концептуальный фон вложенных пространств — [`spatial-model.md`](./spatial-model.md). Здесь — **инварианты ощущения и движения** на столах проектов/конструктора.

---

## Пространство

1. **Масштаб, не страницы.** Режимы — уровни приближения одного стола на одном маршруте, а не набор несвязанных экранов.
2. **Центр + сателлиты.** У режима один центр (Ева / рантайм / hub агента / канал) и сателлиты на верхней орбите.
3. **Packed-орбита.** Соседи на минимальной хорде; дугу до максимума не растягивать. Ближе к центру, чем к верхнему/боковому chrome; обычно в пределах ~½ высоты стола.
4. **Одна метафора раскладки** у родственных столов (проекты вокруг Евы ≈ агенты вокруг рантайма); меняются константы, не идея.

## Движение

5. **Один заход.** В переходе все элементы обоих режимов начинают анимацию одновременно — без фаз collapse → flight → reveal.
6. **Непрерывность объекта.** То, по чему кликнули, летит и *становится* следующим центром (иконка проекта → место рантайма, агент → hub конструктора, Ева → её hub).
7. **Одно место — одна иконка.** Два значка на одном сиденье (twin) и блик в конечной точке — баг дизайна, не «особенность transition».
8. **Handoff.** Сначала посадить/показать цель (opacity мгновенный, без fade); на следующем кадре убрать летящую. Порядок в коде: `features/projects/motion/handoff.ts` (`HANDOFF_PHASES`).
9. **Фокус не в collapse.** Сателлиты могут схлопываться в центр; выбранный объект летит своим путём и не уезжает в якорь вместе с остальными.
10. **Вылет из центра.** Вход на стол — сателлиты появляются из центра; выход — возвращаются в него. Лёгкий stagger — физика внутри одного захода, не вторая фаза.

Реализация выхода: пока идёт leave-pass, вложенный стол держит slug’и через `LeaveHold` (`features/projects/motion/leaveHold.ts`) — роутер очищает URL раньше, чем заканчивается анимация.

## Приёмка перехода (чеклист)

Туда и обратно для затронутого режима:

- [ ] Нет последовательных фаз `await` вместо одного захода
- [ ] Нет twin / пустого кадра / блика opacity на сиденье
- [ ] Фокус не схлопнут с сателлитами во время полёта
- [ ] Сателлиты входят/выходят из центра, а не «мигают» на орбите
